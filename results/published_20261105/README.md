- 데이터: `dev_clear` 28건, 샘플당 1회. 워밍업 1건 제외, 미평가 0건.

- 내용 판정: 보존율은 모델 추정 점수, 왜곡·추가 점수는 0.5 이상이면 발생으로 분류.

과거 기준의 사실별 보존율과 Laya 추정 보존율은 산출 방식이 다르다. 기준 결과는 비교 이력이며, 수치 차이를 곧바로 평가자 정확도의 차이로 해석하지 않는다. 실제 판정에 사용한 가중치·질문·장치 정보는 `judgments.jsonl`과 `summary.json`의 메타데이터를 기준으로 확인한다.

공개본은 전사문·사연 본문·화자 식별자·닉네임·개인 PC 경로·음성을 제외했다. 판정 수치는 원본 그대로다. 원본 입력을 제외했으므로 이 파일들만으로 `eval.judge`나 `eval.report`를 재실행하는 용도는 아니다. 로컬 원본 결과는 별도로 보존한다.
