# 평가지표

2026-11-05 사용자 승인: 로컬 Laya 평가로 전환. 교수님 확인에 따른 사용자 요청으로 사실 개수 기반 micro 보존율을 지표에서 삭제.
이 문서는 현행 평가 기준이다. 규칙·합격선의 임의 변경은 금지한다.

## 평가 지표

| 대상 | 계산 | 합격선 |
|---|---|---|
| ① 내용 보존 | Laya 추정 보존율: 각 요청의 0~10 점수 × 10의 평균(macro) | 95% 이상 |
| ① 왜곡·추가 | 원문 사실을 바꾸거나 근거 없는 사실을 추가한 사연 수 / 판정된 사연 수 × 100 | 합산 5% 이하 |
| ② 형식 | R1~R7을 모두 통과한 사연 수 / 생성되고 형식 판정된 사연 수 × 100 | 90% 이상 |
| ③ E2E | 입력 접수 후 120초 내 재생 가능한 전체 음성을 만든 요청 수 / 전체 요청 수 × 100 | 95% 이상 |
| ④ 통합 | E2E 성공·추정 보존율 100%·왜곡/추가 없음·형식 통과를 모두 만족한 요청 수 / 전체 요청 수 × 100 | 90% 이상 |

모든 발생률/통과율은 분자·분모를 표시한다. 보존율은 사연별 점수 평균과 평가 건수를 표시한다.
보존율은 학습된 모델의 추정이다. 사실별 확인 정답과 같은 값으로 주장하지 않는다.
통합의 보존 조건은 모델이 반환한 점수 10.0(100%)에만 적용하며 99% 등으로 완화하지 않는다.
왜곡·추가의 연속 점수는 보정된 정답 확률이 아니다. 점수 0.5 이상을 오류 있음으로 판정한다.
각 왜곡률·추가율 및 둘 중 하나라도 있는 합산 발생률을 따로 저장한다.

## 판정 모델과 입력

- 모델: `models/laya/`의 실제 400건 기반 보완 학습 Laya. 모델 버전과 SHA256은 config에 고정한다.
- 입력: 별명, 원본 라벨 정답 전사문, 생성 사연. STT 결과를 정답 기준으로 대체하지 않는다.
- 내용과 형식의 질문은 `models/laya/questions.json`에 고정한다. 내용 가중치와 질문은 검증 없이 변경하지 않는다.
- R2·R6은 코드가 판정한다. R5는 코드와 Laya가 모두 통과해야 한다.
- 판정은 생성과 분리한다. 요청마다 원시 점수·판정·모델 및 질문 해시·입력 해시·장치·오류를 남긴다.
- Laya는 근거 문장을 생성하지 않는다. 원문·생성 사연과 점수를 보관하고 근거를 임의로 만들어 넣지 않는다.
- 입력 잘림, 비정상 점수, 누락된 기준 원문, 추론 오류는 미평가. 미평가 건수와 ID를 표시하고 재실행 대상에 둔다.
- 같은 입력/모델/질문/설정으로 완료한 요청만 재실행에서 건너뛴다. 이전 평가자 기록과 혼합하지 않는다.

## ① 내용 판정 기준

- 표현이 달라도 의미가 같으면 보존, 누락이나 인물·장소·시점·사건 변경은 미보존.
- 핵심 내용은 서로 다른 사건과 명시된 감정이다. 같은 행위의 세부는 묶고 반복은 중복 계산하지 않는 방식으로 학습했다.
- 왜곡: 인물·관계·사물·숫자·장소·시점·부정긍정 변경, 가정을 실제 사건으로 바꿈, 질문을 진술로 바꿈.
- 추가: 원문에 없는 구체적 사건·결과·인물·장소·숫자·이유·시점·사실인 것처럼 제시한 해석.
- 감정·분위기 묘사, 전달 말투, 군말 삭제, 같은 뜻 표현, 원문 부수 내용은 추가가 아니다.
- 마지막 마무리 문장 자체는 내용 추가 판정에서 제외하고 R7로 확인한다.
- 생성 실패/빈 사연은 보존율 0%, 왜곡 및 추가 있음으로 집계한다.
- 판정 실패는 내용 실패와 구분하여 미평가로 남긴다. 미평가가 있으면 잠정 결과이다.

## ② 형식 규칙

| 규칙 | 통과 기준 | 담당 |
|---|---|---|
| R1 | 서술자가 주인공을 나·저·내가·제가 등 1인칭으로 말하거나 지정 별명 대신 다른 이름으로 부르면 실패. 우리 가족·우리 동네 같은 집단 표현, 다른 인물 관점의 엄마·할머니 같은 관계 호칭은 허용 | Laya |
| R2 | 공백 포함 308자 이하. 하한 없음. 후처리된 최종 사연 문자열을 셈 | 코드 |
| R3 | 주인공 소개 도입 → 이야기 본문 → 마무리 구조. 문단 수 무관 | Laya |
| R4 | 서술 문장이 존댓말로 끝남. 해요체·습니다·답니다·존대 방언 허용. 타인의 말 인용은 제외. 반말 어미나 좋습니다요·된다요 같은 깨진 어미는 실패 | Laya |
| R5 | 전화번호·주소·주민번호·특정 병원명·원문에 없는 사람 이름 금지. 원문에 있던 사람 이름과 활동 장소 허용 | 코드+Laya |
| R6 | 오늘의 사연 주인공은 으로 시작 | 코드 |
| R7 | 마지막 문장이 주인공 마음에 공감하거나 청취자에게 주인공께 이야기를 들려달라고 권함. 부재·일반론·훈계·1인칭·근거 없는 사실이면 실패 | Laya |

R5 일반 명사 예외: 지정병원·종합병원·대학병원·동네병원·요양병원·개인병원·큰병원.
기존 정규식에 더해 원본 전사문에서 확인된 붙여 쓴 병원명을 사연의 공백 정규화 문자열과 대조한다.
이 검사는 새로 추가된 모든 병원명이나 애매한 기관명까지 해결하는 이름 인식기가 아니므로 Laya 판정을 병행한다.
각 규칙의 통과/실패와 코드 검출 구절을 모두 저장한다.

## ③ E2E와 ④ 통합

- 입력 접수: wav를 STT에 넘기는 시점. 종료: 전체 TTS wav 저장 완료. 단조 시계로 측정.
- 재생 가능: 파일 존재·비어 있지 않음·디코딩 가능·전체 무음 아님. 음성 길이는 무음 제거 없이 기록.
- 순차 실행. 워밍업 1건은 모든 집계에서 제외. 반복 수는 config의 eval.reps이며 run.json에 기록한다.
- Laya 평가 시간은 E2E 시간에 포함하지 않는다.
- 텍스트만 평가하거나 이전 출력을 재판정한 것을 새로운 음성 E2E 실험으로 표기하지 않는다.
- 생성 실패·120초 초과·미평가 요청은 통합 미통과.
- 통합은 모델 추정 보존율을 사용한 운영 판정이며, 실제 오류를 모두 검출했다는 보장이 아니다.

## 데이터와 저장

AI Hub 중·노년층 한국어 방언의 1인발화 질문 답하기를 사용한다. 따라말하기·2인발화는 제외.
원본 음성·라벨 정답 전사·화자·질문·주제·별명과 생성 출력을 보관한다. 생성 입력과 평가 기준 원문을 구분한다.

`results/{run_id}/`: run.json, config.yaml, pipeline.jsonl, judgments.jsonl, records.jsonl, summary.json, audio/.
생성 실패·판정 실패는 해당 ID와 원인을 남긴다. 분모가 없는 지표는 0%로 조작하지 않고 미평가로 표시한다.
평가자·가중치·설정이 다른 과거 결과는 단순 증감으로 비교하지 않는다.
