#  한계점

갱신: 2026-11-05


| 항목         | 한계                                                                        |
| ---------- | ------------------------------------------------------------------------- |
| 정답 원문 의존 | 현재 내용 평가는 데이터셋의 원본 라벨 정답 전사문과 생성 사연을 비교한다. 실사용에서는 정답 전사문이 없어 같은 방식의 보존·왜곡·추가 평가를 지원하지 않는다. 기존 수치는 정답 원문을 제공한 데이터셋 평가 결과이며, 사연만 입력한 판정 성능을 뜻하지 않는다. |
| STT 오인식    | 흐린 발음·방언·고유명사를 잘못 전사하면 오류가 생성 사연에도 이어질 수 있다.                              |
| Laya 판정 오차 | 실제 왜곡·추가·누락을 놓치거나 정상 내용을 오류로 판단할 수 있다. 보존율 100%도 실제 내용이 모두 정확하다는 보장은 아니다. |
| 형식 판정      | 1인칭·인용문·존대 방언·깨진 어미를 구분할 때 오판이 남는다. 병원명도 띄어쓰기 보완만으로 모든 변형을 검출하지는 못한다.     |
| 사연 생성·후처리  | 308자 초과, 중복 마무리, 1인칭 잔존, 불완전한 문장을 완전히 방지하지 못한다.                           |
| 판정 근거      | Laya는 점수와 판정만 반환하므로 어느 구절이 왜 틀렸는지 자동으로 설명하지 못한다.                          |
| 긴 입력       | 현재 입력 한도를 넘겨 잘리는 사례는 판정하지 못하고 미평가로 남는다.                                   |
| 검증 범위      | 독립된 새 화자·주제와 다양한 오류 유형에 대한 검증이 충분하지 않다. 소규모 시험 결과를 전체 성능으로 일반화할 수 없다.     |
| Jetson 구동  | 실제 배포 장치에서 전체 모델의 메모리 사용량과 E2E 성공률을 아직 확인해야 한다.                           |
